## Before You Build ✅

- [ ] Read the Official Rules (Devpost Rules tab)

## Build Requirements ✅

- [ ] Working software application using Kiro (IDE, CLI, Web, and/or Kiro Crew)
- [ ] Uses Kiro meaningfully (Crew agents, hooks, specs, steering, MCP, powers — documented in write-up)
- [ ] Public GitHub repository (NOT GitLab or BitBucket)
- [ ] Repo contains ALL source code, assets, and instructions
- [ ] Open source license file (MIT) — detectable in GitHub About section
- [ ] `/.kiro` directory at repo root (specs, hooks, steering present)
- [ ] `/.kiro` NOT added to `.gitignore` (disqualifying if ignored)
- [ ] URL to working app(s) ready
- [ ] Login credentials + instructions prepared (if app needs auth)
